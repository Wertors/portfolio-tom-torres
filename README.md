# Portfolio de Tom Torres

Portfolio d'étudiant en BTS SIO option SISR, en alternance au service informatique de l'Agglomération Melun Val de Seine.

Site statique (HTML, CSS et JavaScript, sans dépendance), publié avec GitHub Pages.

- `index.html` : tout le site. Chaque rubrique (À propos, Alternance, Projets, Compétences, Parcours, Contact) s'affiche comme une page séparée grâce à l'ancre de l'URL, par exemple `#projets`.
